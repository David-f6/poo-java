# POO Java

Exercices de programmation orientée objet en Java (TD de cours).

## Contenu

- `src/` : sources Java du TD2 (formes géométriques : `Shape`, `Circle`, `Polygon`, `Point`…)

## Compiler

```bash
javac -d out src/*.java
```

## Entraînement au contrôle

Exercices dans `entrainement/exN/` (énoncé, test fourni, sortie attendue). Dans Claude Code :

- `/corrige ex2` : corrige l'exercice en mode tutorat ;
- `/exercice` : prépare l'exercice suivant.
